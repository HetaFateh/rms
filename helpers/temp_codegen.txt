Edit Existing Program Flow:
1. Login as Admin
2. Search the existing program by name
3. Click edit button
4. Click the date picker than change the date to be longer then before
   this is the locator (just for example) :    await page.goto('https://dashboard.rms.dev.atklik.xyz/auth/login');
                            await page.getByRole('textbox', { name: 'Select date range' }).click();
                            await page.getByRole('gridcell', { name: 'Choose Tuesday, May 19th,' }).click();
                            await page.getByRole('gridcell', { name: 'Choose Sunday, May 31st,' }).click();
   the first date choosen should be refer to the day before the current day (e.g. if today is May 20th, choose May 19th)
   the last date choosen should be the first day plus 12 days (e.g. if the first date is May 19th, choose May 31st)
5. Click save button
6. Logout
7. Login as Approver
8. Go to Approval Program feature
9. Search the program by name
10. Click the "Approve" button and so on
11. Logout
